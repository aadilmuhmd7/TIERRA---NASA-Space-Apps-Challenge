TIERRA

Terrestrial Analog Explorer

TIERRA is a project our team Cosmos Redshift 7 building for the NASA Space Apps Challenge 2026.

The idea is simple: Earth has some pretty unusual environments that can help us understand what conditions might be like on the Moon and Mars. TIERRA brings these places together on an interactive map so people can explore them and learn what makes each location useful for planetary research.

What can you do with it?

Explore analogue locations around the world on a map.

Find places relevant to Moon and Mars research.

Learn about the geology and environmental conditions of each location.

Compare Earth environments with conditions on the Moon and Mars.

Browse research information and scientific references.

Add your own custom markers.

Running the project

Clone the repository:

git clone YOUR_REPOSITORY_URL

Open the project folder and start a local server. If you have Python installed, run:

python -m http.server 8000

Then open http://localhost:8000 in your browser.

A note on the project

Terrestrial analogues aren't exact copies of the Moon or Mars. They're places on Earth that share certain features or conditions with them. TIERRA is about exploring those similarities, understanding the differences, and seeing what we can learn from them.
